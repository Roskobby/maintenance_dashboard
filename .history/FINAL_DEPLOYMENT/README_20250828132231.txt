GPMS MAINTENANCE DASHBOARD
========================

SIMPLE INSTRUCTIONS:
--------------------
Double-click "Start Dashboard.bat" 

That's it!

WHAT IT DOES:
-------------
- Checks if Python is installed
- Installs required packages (only if needed)
- Detects existing packages (no re-installation)
- Starts the dashboard in your browser

NOTES:
------
- First time may take 5-10 minutes to install packages
- Subsequent runs are much faster (detects existing packages)
- Dashboard runs at http://localhost:8501
- Close the black window to stop
- Works from shared folders
- Multiple people can use it from different computers
